# YSF XSEED 语音版中文补丁构建工具

本项目用于从用户自行准备的游戏文件和[原汉化补丁](https://keylol.com/t107903-1-1)，在本地生成适用于《伊苏：菲尔盖纳之誓》XSEED 语音版的中文补丁。

## 支持版本

- 2017 英文版：Steam Build 2249175；
- XSEED 语音版：Steam Build 4766666；
- 原汉化补丁：以上述链接提供的版本为底本。

构建器会核验输入文件的 SHA-256；文件版本或内容不符时会停止，避免把固定地址和脚本映射应用到未知版本。

## 使用方法

仓库中只提供构建代码和说明。请进入 [`builder`](./builder/) 目录并阅读[完整使用说明](./builder/README.md)。

使用者需要自行准备：

1. 2017 英文版游戏文件；
2. XSEED 语音版游戏文件；
3. 已解压的原汉化补丁。

本仓库不提供游戏文件、原汉化补丁文件或预先生成的补丁成品。

## 项目说明

本项目以原汉化补丁为中文底本，针对 XSEED 语音版完成版本移植、语音与文本对应，以及少量文本修正。本次移植分析、构建脚本编写与版本适配工作由 ChatGPT 完成；原汉化补丁的翻译成果属于原汉化参与者。

本工具不能代替实际全流程游戏测试，也不保证能够修正所有问题。
